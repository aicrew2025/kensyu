0. 全体の地図：どこに何があるか

このシステムは4つの場所でできています。触るのはほぼ①と②だけです。

場所何があるか触る頻度
① GitHub
github.com/aicrew2025/kensyu		申込フォームのファイル（index.html）と日程データ。ここを変えるとフォームの表示が変わる日程変更のたび
② Apps Script
管理シート→拡張機能→Apps Script		自動処理のプログラム（Code.gs）。メール送信・Meet作成・出席記録など日程変更後に1回実行／プログラム更新時
③ 管理スプレッドシート申込・出席・Meet URL一覧などの記録毎日見る（編集は最小限）
④ Supabase
supabase.com のダッシュボード		フォームとApps Scriptの中継サーバー基本触らない（月1回稼働確認のみ）
💡 ログインはすべて support@aicrew.jp のGoogleアカウント（Apps Script・シート・カレンダー・Gmail共通）。GitHubは専用アカウント、Supabaseは招待されたアカウントでログインします。パスワード類は社内の管理簿で引き継いでください。

1. 日程（カレンダー）の変更・追加 — 一番よくある作業

日程のデータは、フォームのファイル index.html の中に書かれています。「GitHub上で書き換える → Apps Scriptで反映ボタンを押す」の2段階です。

共通手順：GitHubで index.html を編集する

  1. ブラウザで github.com/aicrew2025/kensyu を開き、ログインする
  2. ファイル一覧の index.html をクリック
  3. 右上の鉛筆マーク（Edit）をクリック → 編集画面になる
  4. Ctrl+F（Macは⌘+F）で変えたい日付（例：2026-11-04）を検索する
  5. 該当箇所を書き換える（下の「データの読み方」参照）
  6. 右上の緑ボタン Commit changes → もう一度 Commit changes で保存
  7. 1〜2分待って、フォーム（aicrew2025.github.io/kensyu）をスーパーリロード（Ctrl+Shift+R）して表示を確認

データの読み方：1コマ＝この1かたまり

// index.html内の「const D=」以降に日程データが並んでいます
// video=AI動画活用編（現在はこの1コースのみ）、"1"〜"5"=第①〜⑤回
{"date":"2026-11-04", ← 日付（半角・YYYY-MM-DD）
 "wd":"水",           ← 曜日（漢字1文字）
 "time":"14:00〜16:00", ← 時間（〜は全角のまま）
 "cool":"11月"}       ← カレンダー画面のグループ名
⚠️ 書き換えてよいのは " "の中身だけ。カンマ・カッコ・引用符を消すとフォーム全体が動かなくなります（動かなくなったら慌てずGitHubの「History」から直前の版に戻せます。→ FAQ参照）

ケース11コマの日付・時間を変更する（申込者がまだいない場合）

  1. 上の共通手順で、該当コマの date・wd・time を書き換えて保存
  2. カレンダー（support@）で旧日程のMeet予定を削除する（タイトルで検索）
  3. 管理シートのMeet URL一覧から旧日程の行を削除する
  4. Apps Scriptで preCreateAllMeets を実行 → 新日程のMeetが作られ、一覧に追加される

ケース2新しい期の日程を追加する（例：来年1月〜3月分）

  1. 各コース×各回に、新しい日程のかたまりをカンマ区切りで追記する。既存のかたまりをコピーして日付・曜日・時間・グループ名（例："1月"）を変えるのが安全
  2. 保存してフォームで表示確認（カレンダー表示に新しい月が出るか）
  3. Apps Scriptで preCreateAllMeets を実行（新しいコマのMeetだけが追加作成される。既存分は重複しない）
💡 数が多いとき（期まるごと等）は、自分で書き換えるよりAIに頼むのが確実です → 下の「3. AIに頼む」

ケース3すでに申込者がいるコマを変更する

フォームの書き換えだけでは申込済みの人には伝わりません。以下も必ずセットで：

  1. ケース1の手順で日程データとMeetを更新
  2. 申込済みの受講者に変更案内メールを送る（新日時と新Meet URL）
  3. カレンダー：新しいMeet予定に受講者を招待し直す
  4. 管理シート：受講記録・_リマインドの該当行の日付を修正

ケース4あるコマを休講（削除）にする

  1. index.htmlから該当のかたまりをカンマごと削除（前後のカンマが二重にならないよう注意）
  2. カレンダーの該当Meet予定を削除、Meet URL一覧の行も削除
  3. 申込者がいた場合はケース3の②〜④で振替対応

2. プログラム（Code.gs）の更新と実行

関数を実行する（preCreateAllMeets など）

  1. 管理スプレッドシートを開く → メニュー「拡張機能」→「Apps Script」
  2. 画面上部のプルダウン（「実行」ボタンの左）から関数名を選ぶ
  3. ▶ 実行をクリック。権限確認が出たら support@ を選んで許可
  4. 下の「実行ログ」に完了メッセージが出るのを確認
関数名何をするいつ使う
preCreateAllMeetsフォームの日程を読み取り、全コマのMeetを一括作成（既存は重複しない）日程を変更・追加した後
formatMeetSheetMeet URL一覧の並べ替え＋色分け＋整形だけ（安全）一覧が乱れたとき
deleteAllMeets一覧の全Meet予定を削除しシートをクリア全部作り直すときだけ（要注意）
sendReminders翌日分のリマインドを手動送信テストや再送のとき
markAttendance出席の自動記録を手動実行テストのとき

Code.gs 自体を差し替える（プログラム更新時）

  1. Apps Scriptエディタで Code.gs を開き、全選択（Ctrl+A）→ 新しい内容を貼り付け → 保存（Ctrl+S）
  2. 右上「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→ デプロイ
⚠️ 「新しいデプロイ」は絶対に選ばないこと。URLが変わって申込が届かなくなります。必ず「デプロイを管理」から既存デプロイの新バージョン更新を選びます。（間違えてしまったら → FAQへ）

3. 自信がないときは：AIに頼む（Claude Code不要）

このシステムはAI（Claude）が構築しました。引き継いだ人も、ブラウザ版のClaude（claude.ai）に頼めば同じように更新できます。特別なツールは不要です。

  1. claude.ai にログインし、新しいチャットを開く
  2. GitHubで index.html（または Code.gs）を開き、Rawボタン → 全選択してコピー、チャットに貼り付ける（ファイル添付でもOK）
  3. やりたいことを日本語で伝える。例：
    「これは研修申込フォームです。日程データ（const D）の11月分を、次の日程に差し替えて、ファイル全体を返してください：AI動画①=11/5(木)14:00〜16:00、…」
  4. 返ってきたファイルをGitHubにアップロード（Add file → Upload files で上書き）
  5. フォームの表示を確認 → Apps Scriptで preCreateAllMeets を実行
✅ 頼むときのコツ：「何のファイルか」「どこを」「どう変えたいか」「ファイル全体を返して」の4点を伝える。変更後は必ず自分の目でフォームの表示を確認する。

4. 困ったら（よくあるトラブルと復旧）

症状復旧方法
index.htmlを編集したらフォームが真っ白/壊れたGitHubで index.html を開く → 「History」→ 壊れる前の版を開く → 「Raw」で中身をコピー → 編集画面に貼り直して保存（＝元に戻る）
申込が届かなくなった（誤って「新しいデプロイ」をした）Apps Scriptの「デプロイを管理」で新しいURLをコピー → Supabaseダッシュボード → Edge Functions → submit-registration 内の GAS_URL を新URLに書き換えてDeploy（またはAIに依頼）
フォームは動くが確認メールが来ないApps Scriptのデプロイが最新版か確認（デプロイを管理→新バージョン）。support@に届く【申込エラー】メールの内容も確認
Meetが作られない・録画が配布されないApps Scriptの「実行数」（時計マーク）でエラーを確認。support@のアラートメールに対応方法が書かれている
原因がわからない症状・直前にやったこと・エラーメールを添えて claude.ai に相談（Code.gsとindex.htmlを貼ると精度が上がる）
